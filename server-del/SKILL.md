# 删除服务器

从服务器列表中移除指定服务器。

## 数据文件

服务器数据存储在 `~/.claude/servers/servers.json`。

## 执行步骤

1. 从用户消息中获取服务器名称
2. 读取 JSON，精确查找该名称
3. 如果未找到，尝试模糊匹配（name 中包含输入关键词）并给出建议
4. 展示该服务器的信息供用户确认
5. 用户确认后，从数组中移除
6. 写回 JSON 文件
7. 确认删除成功

## 用户输入格式

- `/server-del prod-web` — 按名称删除
- "把 test-server 删掉"

## 确认流程

```
确认删除以下服务器？
  名称: prod-web
  地址: 192.168.1.100:22
  用户: root
  备注: 生产服务器

请确认 (y/n):
```

**不使用 AskUserQuestion 工具**，直接在输出中请求用户确认，等用户回复后再执行删除。

## 删除成功输出

```
已删除服务器: prod-web (192.168.1.100)
```
